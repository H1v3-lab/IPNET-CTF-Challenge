# IPNET-CTF-Challenge

Arborescence générée pour 30 challenges CTF :
- 10 challenges **Cryptographie RSA**
- 10 challenges **Password Cracking**
- 10 challenges **SSH & Réseau**

Chaque dossier de challenge suit le format `[ID]-[NOM-DU-CHALLENGE]` et contient un `README.md` avec :
- Nom du challenge
- Description narrative (cyber-espionnage)
- Difficulté et points
- Format du flag `IPNET{mot_de_passe_ou_cle}`
- 3 hints graduels
- Solution (write-up) avec commandes exactes (John, Hashcat, Python)
